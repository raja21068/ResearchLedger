# PaperOrchestra / Section Writing

## Research Method

Draft with the actual venue template and tracked section map; maintain consistent terminology across sections, source keys, and evidence-slot IDs. Discuss only experiments specified by inputs. Use conditional language for unmeasured predictions.

## Inputs

Existing manuscript state, available citations, study protocol and documented result slots. Do not claim external verification when source checks were not conducted.

## Reference

Read the [bundled upstream PaperOrchestra prompt](../../vendor/paperorchestra/methods/prompts/section_writing_agent.py) as methodological background. Apply [the master writing contract](../paper-orchestra/SKILL.md) in case of conflict, especially its prohibition on fabricated results and unverified references.

## Expected Output

Actionable, inspectable manuscript-stage artifacts and an explicit list of unresolved evidence dependencies.
