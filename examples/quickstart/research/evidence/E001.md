# Evidence: E001

## Claim
The baseline classifier reaches over 90% accuracy on the held-out split.

## Experimental Context
Same config (`configs/base.yaml`), two different seeds (42, 43), same held-out split.

## Result
- R0001 (seed 42): accuracy = 0.9137
- R0002 (seed 43): accuracy = 0.9089

## Observation
Both independent seeds clear the 90% threshold with a tight spread (< 0.5 points) — this is what
actually earns `verified` here: not one run completing, but two independently-seeded runs agreeing.
A single run on its own would only justify `checked` (see
[run-ledger.md](../../../reference/run-ledger.md#status-vocabulary)).
