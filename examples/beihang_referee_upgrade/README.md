# Beihang Referee upgrade — offline smoke test

This directory includes **software-testing artifacts**, not expert review judgments of EvidenceQuorum.

- `review.md`: report generated by the actual Beihang Referee core pipeline using its checked-in scripted fixture and bundled demonstration manuscript, plus the user's supplemental senior-review rubric.
- `evidencequorum_pdf_intake.json`: offline structural inspection of the actual 5-page EvidenceQuorum PDF; the PDF's scientific quality was **not** assessed by this command.

A review on the actual EvidenceQuorum paper requires a supported live provider, a new full manuscript review, scholarly verification where necessary, and independent human assessment. Do not attribute `review.md` to EvidenceQuorum.
